The Problem

No single vendor has the complete picture of global data center infrastructure.

The data center industry is booming — but every vendor tracks different facilities, uses different schemas, reports different capacity definitions, and geocodes to varying levels of precision. Some report facility power, others report IT load. Some track hyperscaler campuses, others focus on colocation buildings.

Our team needed a way to ingest, harmonize, deduplicate, validate, score, and visualize data from all of these sources — and then repeat it on demand as new data arrives. Not a one-off analysis. A production pipeline.

“What used to take days of manual spreadsheet work now runs end-to-end in minutes with a single command.”

Universal Campus ID (UCID)

A spatial proximity clustering algorithm assigns human-readable, source-agnostic campus identifiers. Records from different vendors within 500 meters receive the same UCID — enabling cross-source deduplication without requiring vendors to share ID systems.

Format: {country}-{state}-{city}-{nnn}  (e.g., US-VA-Ashburn-001)

Systematic error & variance analysis
Composite Scoring Formula
Score = (Volume × 15%) + (Core × 30%) + (Capacity × 25%) + (Location × 20%) + (Richness × 10%)

Source Accuracy Grades

Tier-Weighted Scoring

Hyperscaler accuracy receives 60% weight in the composite score — because knowing whether AWS or Microsoft has 500 MW or 800 MW at a campus matters more than getting the capacity right on a 2 MW colocation closet. The scoring system reflects business priorities, not just raw statistics.

21 accuracy analysis scripts cover spatial overlap, capacity variance, net new site detection, multi-source comparison, and air permit validation.

Key Lessons Learned

01

Documentation is a Force Multiplier

56 versions of the AI context document became the project's memory. Any collaborator — human or AI — could pick up exactly where the last session left off.

02

Idempotent Pipelines Save Sanity

Making every script safe to re-run (auto-delete before insert) meant I could iterate fearlessly. Break something? Just re-run.

03

Validation IS the Product

The diagnostic report became more valuable than the raw data. Stakeholders didn't just want answers — they wanted confidence in the answers.

04

Start With the Ugly Version

My first scripts were messy. But they worked. Then I refactored, then refactored again. 65 archived scripts are proof of iteration.

05

AI Accelerates Learning, Not Thinking

AI tools didn't write the code — but they compressed the learning curve dramatically. I could ask "how do I do X in arcpy?" and immediately apply it.
