3-Field Company Structure

Created separate fields for different use cases to prevent false matches in spatial clustering:

Field Purpose Example
company_source Raw vendor value "Amazon Web Services, Inc."
company_clean Distinct canonical names (UCID clustering) "AWS", "Equinix", "Digital Realty"
company_clean_filter XB filtering (hyperscalers only) "AWS" or "Colo - All Other"
🐛

Semianalysis ETL Bug Fixed

Discovered and fixed a bug where planned_plus_uc_mw wasn't being written to gold tables. Match rate improved from 57.2% to 99.6%.
