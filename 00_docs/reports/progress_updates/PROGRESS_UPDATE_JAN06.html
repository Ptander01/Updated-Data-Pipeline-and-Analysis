⚡ Live Capacity Accuracy Calculation

New Function: calculate_capacity_accuracy_stats()

Calculates capacity accuracy metrics for each source at report generation time, enabling live tracking as input data refreshes.

  • Compares source capacity values against Meta Canonical IT Load (ground truth)
  • Uses spatial matching to link source records to Meta buildings
  • Optimal field selection per source (mw_2023 for Semi, commissioned_power_mw for DCH)
  • Deduplicates to closest match per Meta building
  • Calculates MAPE and bias percentage per source

Capacity Grade Thresholds

Grade MAPE Range Interpretation

B15-25%Good — minor differences, likely timing variance
C25-40%Moderate — may indicate definition differences
D40-60%Poor — significant accuracy concerns
