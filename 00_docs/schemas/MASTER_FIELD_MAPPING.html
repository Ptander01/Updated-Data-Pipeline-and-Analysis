Field Categories Reference

▼

Primary Key Fields

  • unique_id — Source-specific unique identifier
  • ucid — Universal Campus ID (cross-source)
  • building_ucid — Building-level UCID

Required Fields (all sources must provide)

  • latitude, longitude — Point geometry
  • company_source — Raw company name
  • source — Source system identifier

Capacity Fields Priority

PriorityFieldUsage
1commissioned_power_mwCurrent operational (use for comparisons)
2full_capacity_mwTotal buildout potential
3mw_YYYYYear-by-year forecasts (Semianalysis only)
