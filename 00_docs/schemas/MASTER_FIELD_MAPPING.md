## 7. Field Categories Reference

### Primary Key Fields
- `unique_id` - Source-specific unique identifier
- `ucid` - Universal Campus ID (cross-source)
- `building_ucid` - Building-level UCID

### Required Fields (all sources must provide)
- `latitude`, `longitude` - Point geometry
- `company_source` - Raw company name
- `source` - Source system identifier

### Capacity Fields Priority
1. `commissioned_power_mw` - Current operational (use for comparisons)
2. `full_capacity_mw` - Total buildout potential
3. `mw_YYYY` - Year-by-year forecasts (Semianalysis only)

### Date Field Priority
1. `actual_live_date` - When facility went operational
2. `construction_start_date` - Ground-breaking (SA only)
3. `data_vintage` - When source data was published
