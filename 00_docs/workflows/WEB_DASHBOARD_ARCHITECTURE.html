📡 API Endpoints

GET /api/features/{layer} GeoJSON with filters (company, source, status, region, etc.)
GET /api/statistics Pre-computed KPIs and aggregates
GET /api/lookups Unique values for filter dropdowns
GET /api/export/csv/{layer} Download filtered data as CSV
GET /api/reload Refresh cache after re-exporting GeoJSON

🚀 Server Deployment

When migrating to a shared network server, copy essential files and regenerate dependencies locally.

✅ COPY These (~50-60 MB)

  • 📁 backend/main.py — API server
  • 📁 backend/requirements.txt — Python deps
  • 📁 frontend/src/ — React source
  • 📁 frontend/package.json — Node deps
  • 📁 frontend/*.config.* — Config files
  • 📁 data/*.geojson — Data files
  • 📁 data/*.json — Lookups/stats
  • 📁 start_dashboard.ps1 — Startup

❌ DO NOT Copy (~300 MB)

  • 📁 node_modules/ → npm install
  • 📁 dist/ → npm run build
  • 📁 .vite/ → Auto-generated
  • 📁 __pycache__/ → Auto-generated

These contain platform-specific binaries that must be regenerated on the target machine.

Migration Command

# Copy using robocopy (excludes large generated folders) robocopy "C:\path\to\web_dashboard" "\\server\share\Dashboard" /E /XD node_modules __pycache__ .vite dist

Server Setup

# 1. Install Node dependencies cd \\server\share\Dashboard\frontend npm install # 2. Install Python dependencies cd \\server\share\Dashboard\backend pip install -r requirements.txt # 3. Start dashboard (binds to all interfaces for network access) cd \\server\share\Dashboard .\start_dashboard.ps1

Update Data on Server

1️⃣ Export Locally
Run export_to_geojson.py in ArcGIS Pro on your machine
2️⃣ Copy Data Files
Copy data/*.geojson and data/*.json to server
3️⃣ Reload Cache
Visit http://server:8000/api/reload
