📋 Methodology

How This Analysis Works (Aligned with SA vs DCH Workflow):

This comparison follows the methodology established in SA_VS_DCH_COMPARISON_WORKFLOW.md and UCID_SA_DCH_IMPROVEMENT_PLAN.md.

Matching Mode Used: Building-Level Spatial (1-to-1 Optimal)
  • 1-to-1 Optimal Matching: Each record matches at most ONE counterpart. Uses a greedy algorithm prioritizing closest distances first, ensuring symmetric pair counts.
  • Distance Threshold: 500m default. Records farther apart are considered unmatched.
  • Company Normalization: Company names normalized (e.g., "Amazon Web Services" → "AWS") for company match flagging.
Available Matching Modes:
ModeDescriptionBest For
spatial Distance only (current) Understanding raw record overlap
company_aware Distance + same company required Preventing false matches at multi-tenant sites
ucid (recommended) UCID-based campus matching Accurate site counting, requires post-ingestion pipeline
Questions This Analysis Answers:
  • What percentage of NPM records have a corresponding Orennia record nearby? (Overlap rate)
  • For matched pairs, do they agree on company attribution?
  • How closely do capacity values agree between sources? (MAPE, Bias, Pearson r)
  • Is there evidence that sources share the same underlying data source? (Source Overlap Analysis)
Key Limitations:
  • Building-level granularity: This analysis compares individual building records, not UCID-aggregated campuses. A campus with 5 buildings in Orennia may match 3 buildings in NPM (showing as 3 pairs, not 1 campus).
  • Multi-tenant risk: Without company-aware matching, records from different companies at the same location may be incorrectly matched.
  • Capacity comparisons: Only include pairs where both sources report capacity values.
For More Accurate Campus-Level Comparison:

Run the full post-ingestion pipeline first (run_post_ingestion.py) to generate UCIDs, then use campus-level comparison from gold_campus_full for accurate site counts. See SA_VS_DCH_COMPARISON_WORKFLOW.md for the recommended approach.
